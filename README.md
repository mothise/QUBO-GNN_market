# QUBO-GNN_market

Код и результаты выпускной квалификационной работы в НИУ ВШЭ по теме «Графовые нейронные сети для задач оптимизации в финансах».

Цель работы — проверить, насколько решатели семейства PI-GNN пригодны для задач выбора активов. Это графовые нейронные сети, которые обучаются без учителя на QUBO-постановке одной задачи. Три сети семейства и метод без сети запускаются на двух задачах, построенных по рыночным данным; их ответы сравниваются с доказанными оптимумами и с простыми классическими методами.

## Задачи

- `dense_tier` — выбор портфеля из K активов равными долями по критерию «доходность — риск»: QUBO-задача с плотной матрицей. Наборы экземпляров от 28 до 1 203 активов, вес риска q от 0.9 до 1.
- `sparse_tier` — наибольшее независимое множество на рыночном графе, где ребро соединяет активы с корреляцией выше порога: QUBO-задача с разреженной матрицей. Невзвешенный вариант и взвешенный, в котором вес вершины равен средней доходности актива (постановка Schuetz et al., 2022), с единым штрафом и со штрафом на ребре.

## Решатели

| Решатель | Источник | Где в коде |
|---|---|---|
| PI-GNN | Schuetz, Brubaker, Katzgraber (2022) | `shared/solver_family.py` |
| CRA-PI-GNN | Ichikawa (2024) | `shared/solver_family.py` |
| QRF-GNN | Pugacheva et al. (2024) | `shared/gnn.py` (в репозиторий не входит, см. ниже) |
| PQQA, метод без сети, для сравнения | Ichikawa, Arai (2025) | `shared/pqqa.py` |

Сети и PQQA запускаются с гиперпараметрами своих статей; отступления от них перечислены в тексте работы.

## С чем сравниваются ответы

- **Доказанные оптимумы.** Задача о портфеле: Gurobi и HiGHS (`dense_tier/experiments/certify_gurobi.py`, `certify_highs.py`). Графы: HiGHS и CP-SAT из OR-Tools (`sparse_tier/mis_exact.py`, параметр `--engine` в `sparse_tier/screen.py`).
- **Классические методы.** Greedy, рестарты из случайного начала и локальный поиск (`dense_tier/hardness_screen.py`, `sparse_tier/mis_baselines.py`), с указанием времени.

## Структура

| Папка | Содержание |
|---|---|
| `dense_tier/` | задача о портфеле: оценка моментов, QUBO, отбор экземпляров, запуск сетей |
| `dense_tier/experiments/` | доказательство оптимумов, PQQA, трудные экземпляры при q от 0.9 до 1, точный минимум релаксации, проверки |
| `sparse_tier/` | рыночные графы, отбор и доказательство оптимумов, запуск сетей и PQQA, контрольные опыты |
| `shared/` | общий код: загрузка данных, решатели, метрики |
| `*/results/` | списки экземпляров и файлы отбора с эталонными решениями |

## Что не входит в репозиторий

- **Данные.** Недельные доходности Bruni et al. (2016) нужно положить в `data/bruni/<рынок>/<рынок>.mat`. Другую папку с данными задаёт переменная окружения `DIPLOMA_DATA`.
- **Код QRF-GNN.** Файлы `shared/gnn.py` и `shared/mis.py` в репозиторий не включены. Без них сценарии, которые обучают сети, не запускаются.
- **Файлы запусков.** Хранятся списки экземпляров и файлы отбора; выходные файлы сетей и PQQA воспроизводятся сценариями.

## Основные результаты

**Графы, 42 графа с доказанным оптимумом.** Доля оптимума, которой не хватает ответу, %. У сетей ответ в конце обучения.

| Метод | Невзвешенные | Взвешенные, единый штраф 2 | Взвешенные, штраф на ребре |
|---|---|---|---|
| Greedy, один проход | 3.85 | 3.27 | 3.27 |
| Лучший из 50 рестартов | 0.75 | 1.19 | 1.19 |
| Итерированный локальный поиск, 5 с | 0.00 | 0.08 | 0.08 |
| QRF-GNN | 3.32 | 17.12 | 13.75 |
| CRA-PI-GNN, слои GraphSAGE | 1.55 | 6.47 | 2.32 |
| PI-GNN, слои GCN | 50.79 | – | – |
| PQQA, лучший из 100 параллельных запусков | 0.23 | 6.23 | 7.42 |

**Задача о портфеле при q = 0.9.** Шкала: 0 — случайный портфель, 1 — доказанный оптимум.

| Метод | 22 отмеченных, до 83 активов | 80 независимых окон | 442 актива | 1 203 актива |
|---|---|---|---|---|
| Greedy | 0.981 | 0.997 | 0.991 | 0.990 |
| Случайный портфель с проходом 1-swap | 0.994 | 1.000 | 0.997 | 0.995 |
| QRF-GNN, основная конфигурация | 0.971 | 0.965 | 0.956 | 0.941 |
| QRF-GNN, гиперпараметры статьи | 0.399 | 0.315 | −0.063 | −0.010 |
| CRA-PI-GNN, слои GraphSAGE | – | – | 0.943 | 0.914 |
| PI-GNN | – | – | 0.192 | 0.168 |
| PQQA, выпуклая форма | 0.954 | 0.954 | 0.529 | 0.333 |

- На обеих задачах простой классический метод находится впереди каждой сети.
- Задача о портфеле трудна ближе к минимуму дисперсии и при большом числе активов на неделю данных.
- На графах ответ сетей определяют расписание штрафа, шаг исправления и отдельный вес собственного состояния вершины; на взвешенных графах — ещё и масштаб штрафа относительно весов.
